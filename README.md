## 常见问题

### 搬瓦工库存页面显示有货，就一定能买到吗？

不能保证。库存状态可能在监控刷新后发生变化，最终要看官网订单流程是否允许选择配置并完成结账。发现有货后，先核对套餐、地区和账单周期。

### 官网首页没有某个限量套餐，是不是已经售罄？

不能仅凭首页判断。特殊方案可能通过不同的产品分类或订单入口展示。可以查看相关官方分类；如果最终订单页提示缺货，才说明该入口对应的方案当前无法购买。

### 搬瓦工多久补一次货？

如果官网没有发布明确的补货安排，就无法可靠给出固定日期或频率。第三方推送和监控可作为提醒渠道，但补货预测不是官方承诺。

### 有货的普通套餐可以替代限量套餐吗？

要看限量款对你来说“特别”在哪里。若关键是价格、机房或某条网络线路，普通 KVM 未必等价；若只是需要一台可管理的 VPS，基础套餐可能满足资源需求。应逐项比较配置，而不是只比较套餐名称。

### 购买前最容易忽略什么？

最常见的是计费周期和网络类别。官网基础 KVM 列表中的方案分别按年、半年或月显示价格；特殊地区和网络产品则可能有不同配置与周期。结账前把套餐名称、地区、流量和总价都确认一遍。

**简单结论：**查搬瓦工库存，最终以官网具体订单页面为准。常规 KVM 有公开的六档配置可比较；限量和特殊网络方案则要进入对应分类逐项确认。找不到理想款时，先明确机房、线路或预算哪个条件最重要，再决定等待还是换方案。
